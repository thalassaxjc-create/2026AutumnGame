# 反诈游戏工坊

把反诈宣传素材做成能试玩、投屏和分享的情境游戏。面向班会课堂、社区活动、企业培训、家庭共学和线上传播。内置 36 张案卡和 10 套玩法，每张案卡附有公开来源和可执行的应对建议。

## 启动

需要 Node.js 22.13 或更新版本。在本项目目录运行以下命令，即可打开本地预览。

```powershell
npm ci
npm run build
npm start
```

访问 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。代码修改期间可用 `npm run dev`，自动化测试用 `npm test`。

在同一个局域网内给手机试玩时，用 `npm start -- --lan` 启动。从电脑的局域网地址打开工坊，再发布并生成二维码。已发布游戏的链接由浏览器当前使用的地址生成。

## 演示路线

1. 在「生成工坊」输入「给初二学生讲游戏充值诈骗，做一场 5 分钟班会投屏」。系统识别场景、人群、时长和案卡，生成前可调整。
2. 选「找破绽局」生成。依次找出私下代充、押金或解冻费、脱离游戏平台这些信号，再决定怎么独立核验。投屏时可用数字键选答案、回车提交和继续。
3. 结案后打开「讲解卡」，可以现场用讨论题带复盘、下载 Markdown、打印或复制课后群文案。
4. 从草稿点击「发布分享」，获取可在另一个浏览器打开的链接和二维码。修改过标题或情境的作品会进入审核台，审核通过后原链接生效。

## 内容与数据

- 一句话、案卡、粘贴案例都可作为生成入口。生成器用规则识别相似案卡，再从已整理的虚构情境和防范要点组装关卡。3、5、10 分钟是包含讲解的活动档位。
- 草稿保存在当前浏览器。发布配置、纠错、审核状态和匿名试玩统计保存在服务端的 `.data/studio.json`，可通过 `FRAUD_DATA_FILE` 指定其他持久目录。粘贴的案例原文只用于当前页面匹配。
- 试玩和讲解由同一份游戏配置生成。整理日期、题目解析和公开来源可在图鉴和讲解卡中查看。
- 独立部署可在 `.env` 设置 `HOST`、`PORT` 和 `FRAUD_ADMIN_TOKEN`。公网部署请配置管理口令和 HTTPS，并挂载持久数据目录。默认本机演示可直接打开审核台。
